# LLM CostGuard

**An OpenAI-compatible gateway that cuts LLM spend with caching, context trimming and model routing, and measures how much quality the savings cost.**

CostGuard runs **service-side**. The operator puts it between its own backend services and the LLM provider, and a calling service switches over by changing its `base_url`. Each request passes through five cost levers, ordered from safest to riskiest for quality:

1. **Exact cache:** in-memory, TTL plus LRU.
2. **Semantic cache:** `bge-small` embeddings, in memory or in Qdrant. A per-mode similarity threshold (τ) is calibrated on paraphrase and trap pairs. Guards reject hits that differ in numbers, negation or entities.
3. **Context optimiser:** a cross-encoder reranks the retrieved docs, then a dynamic-k cut keeps only what the token budget allows.
4. **Compressor:** extractive compression of the context block. The system prompt is never touched.
5. **Router:** sends a request to the cheap tier only if the request is not hard *and* its category passed an offline eval gate.

Every stage fails open. A broken stage is skipped and logged, and the request still gets the full prompt on the strong tier. Every request is logged as exactly one `TraceRecord`, which feeds SQLite, Prometheus, drift checks and, optionally, Langfuse.

**Business objective:** cut ShopNest's support-assistant LLM bill by **≥ 30 %** while keeping **≥ 95 %** of baseline answer quality, measured on a frozen request trace. ShopNest is a fictional online store.

**How to read these numbers:**

- **Savings:** cost saved = 1 − Σ cost ÷ Σ cost of the A0 baseline, on the same requests. A0 is the strong tier with the full prompt and no cache.
- **Pricing:** costs are provider list prices from [`configs/prices.yaml`](configs/prices.yaml), with the date they were checked.
- **Quality retained:** the optimised arm's judge score ÷ the baseline's score. The judge grades answers against reference answers, and its pairwise comparisons run in both orders.
- **False-hit rate:** wrong cache hits ÷ *all* requests, not ÷ hits. See [docs/EVALUATION.md](docs/EVALUATION.md).

## Quick start

```bash
python3.12 -m venv .venv && ./.venv/bin/python -m pip install -e ".[dev,dashboard]"
./.venv/bin/python -m pytest -q          # no keys needed: mock backend
make serve                               # http://localhost:8000, mock backend
```

Call it like any OpenAI endpoint:

```python
from openai import OpenAI

client = OpenAI(base_url="http://localhost:8000/v1", api_key="k-support")   # key -> tenant (see below)
r = client.chat.completions.with_raw_response.create(
    model="strong",
    messages=[{"role": "user", "content": "How long do refunds take?"}],
)
print(r.headers["x-costguard-cache"], r.headers["x-costguard-saved-usd"])
print(r.parse().choices[0].message.content)
```

Every response carries `x-costguard-*` headers (cache status, similarity, route, cost, baseline cost, savings, overhead, config hash) and a `costguard` block in the body.

**Other endpoints:**

| Endpoint | Returns |
|---|---|
| `GET /health` | Status and which component is live at each stage |
| `GET /v1/stats` | Hit rate, savings and latency percentiles |
| `GET /metrics` | Prometheus `costguard_*` series |
| `GET /v1/drift` | PSI drift against a frozen baseline |

**Tenancy:** set `COSTGUARD_API_KEYS="key1:tenantA,key2:tenantB"`. The tenant is then taken from the bearer key, never from the request body. Each tenant's mode (`quality`, `balanced`, `economy` or `off`) and whether callers may override it are set under `tenants` in [`configs/policy.yaml`](configs/policy.yaml).

## Backends

| `COSTGUARD_BACKEND` | Strong / cheap tier | Needs |
|---|---|---|
| `mock` (default) | deterministic fake | nothing; used by the tests and CI |
| `mlx` | Qwen2.5-7B / Qwen2.5-1.5B Instruct (4-bit), local on Apple silicon | `pip install -e ".[local]"` |
| `anthropic` | Claude Sonnet 5.5 / Claude Haiku 4.5, native SDK, with prompt caching on the system prompt | `COSTGUARD_ANTHROPIC_API_KEY` in `.env` (see `.env.example`) |
| `openai`, `gemini` | via LiteLLM | the provider's usual key |

**Anthropic endpoint:** the adapter always calls `api.anthropic.com` unless `COSTGUARD_ANTHROPIC_BASE_URL` is set. It deliberately ignores `ANTHROPIC_BASE_URL`, which other tools set for their own proxies.

**Billing:** cache reads and writes are billed at Anthropic's cache prices.

## How the claims are measured

| Piece | Where | What it does |
|---|---|---|
| Frozen trace | `eval/data/trace_v1.jsonl` + sha256 | 600 requests: ~62 % Bitext support queries, ~28 % KB questions with retrieved context, 10 % trap pairs; 30 % exact or near duplicates |
| Record / replay | `eval/cassettes/` | Model outputs are recorded once and replayed, so re-runs and CI are free and deterministic |
| Judge | `eval/judge.py` | Pairwise comparison in both orders (disagreement = tie) plus an absolute grade against a reference |
| Statistics | `eval/stats.py` | Paired cluster bootstrap 95 % CIs; Wilson intervals for rates |
| Ablation | `python -m eval.run_ab` | A0 baseline → A1 exact cache → … → A5 all levers, cumulative, so each lever's increment is visible |
| Threshold calibration | `python -m eval.sweep_threshold` | Hit rate vs false-hit rate per τ on paraphrase, trap and QQP pairs |
| Router gate | `python -m eval.gate_router` | Per-category non-inferiority test of cheap vs strong; writes `configs/router_gate.json` |
| CI eval gate | `python -m eval.ci_gate` | Replays a fixed subset from a cassette; fails the build if any trap pair hits the cache, false hits rise, or quality or savings regress (try `COSTGUARD_TAU_OVERRIDE=0.6`) |
| Report | `python -m eval.report` | Regenerates [docs/RESULTS.md](docs/RESULTS.md) and the block above |

**Caveats:**

- **Eval rows are placeholders.** `eval/data/evalset/seed.jsonl` is AI-written scaffolding (`"author": "seed"`). The graded set is hand-written by the team, one file per author, in `eval/data/evalset/`.
- **Local stand-in pricing.** The local MLX runs bill Qwen at GPT-5.4-mini / GPT-5-nano list prices, a ~12× strong-to-cheap gap. Sonnet 5.5 → Haiku 4.5 is a 2× gap, so router savings on Anthropic will be smaller. Cache savings do not depend on the model pair.
- **Hit rates are an upper bound.** The threshold sweep's hit rates come from paraphrase-heavy data. The savings claims come from the frozen-trace A/B, not from the sweep.

## Operations

- **Docker:** `docker compose up` starts the proxy, Qdrant `v1.19.1` and the dashboard. The image bakes in the embedding models and runs as a non-root user.
- **Render:** [`render.yaml`](render.yaml) deploys the proxy as a free web service; the health check is `/health`.
- **Dashboard:** `make dashboard` opens a Streamlit view of savings, hit rate, route mix and latency.
- **Load test:** `make loadtest` runs Locust against a mock upstream and reports CostGuard's own overhead separately from upstream time.
- **Rollout and rollback:** shadow → canary → full. The router gate file is hot-reloaded, so reverting it is the rollback. A gate measured on a different model pair routes everything to the strong tier. See [docs/RUNBOOK.md](docs/RUNBOOK.md).
