# Gift Cards and Store Credit

## overview

Gift cards and store credit are different kinds of value. Both should be read from the account. Neither balance should be guessed, restored, or converted in chat.

## gift_cards

Gift-card balance and history appear in the account's Gift Cards section when that section is available. The customer enters a gift card only in official checkout or in the account interface. A code is like cash. Do not post it in a public channel, email it to an unverified person, or paste it into support chat. If a card is missing or a code looks used, the customer uses the official help flow. The assistant does not state a dollar balance and does not restore value unless an authoritative account result in the context gives that balance or that restoration.

## store_credit

Store credit is an account balance, often left by a refund or an adjustment. Checkout applies it from the account. It is not typed into the gift-card box. Store credit is not entered as a gift-card code, and a gift-card code is not typed into a store-credit field. Chat cannot convert one into the other. The balance is whatever the account page shows.

## steps

For a gift card, point the customer to the Gift Cards section. For store credit, point them to the account balance at checkout. If they paste a code, tell them not to share it and do not repeat the code in the reply. If they ask for a balance that is not in context, say you do not have an authoritative figure. If the code looks used or the account looks compromised, use official help and the account-security guidance.

## examples

The customer asks whether they should post code ABCD-1234 in a public chat so a friend can check it. No. Treat it like cash and do not post it.

The customer asks, as a tag question, whether they should avoid posting that code. Yes. They should not post it.

The customer says the balance is 50 dollars because they bought the card yesterday. Do not confirm 50 dollars. A purchase story is not an account result.

The customer asks to type store credit into the gift-card box. Explain that store credit is applied from the account and is not a gift-card code.

The customer asks for the value to be restored and for the code to be read aloud. Do neither, unless an authoritative result is already in context. A suspected misuse is an official help case, not a chat-side balance edit.

## agent_rules

Do not claim, restore, or transfer value without an authoritative account result. Do not repeat a gift-card code. Do not ask for a CVV, password, or one-time passcode to look up a card. Do not treat store credit and gift cards as interchangeable codes.
