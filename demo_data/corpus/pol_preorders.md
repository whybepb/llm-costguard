# Preorders

## overview

A preorder reserves an item before it ships. A moving ship date updates the estimate. It does not cancel the order and it does not create a refund by itself.

## rules

The estimated ship date on the order is the current date. If that date moves, the preorder stays active unless the customer cancels it or the order page says otherwise. Cancellation is available only while a cancel control is shown, which is normally before shipment. After the item ships, the shipped rule in the cancellation article applies, and a later return depends on the returns article. A date change is not an automatic refund.

## examples

The ship date slipped by two weeks and Cancel order is still showing. The customer may cancel through that control. The date change did not already cancel or refund the order. The assistant has not cancelled it.

The control is missing because the preorder has shipped. Do not treat the old date change as if cancellation were still open. Use the shipped-order guidance.

## agent_rules

Do not treat a delayed ship date as an automatic cancellation or an automatic refund. Do not invent a replacement ship date that is not on the order.
