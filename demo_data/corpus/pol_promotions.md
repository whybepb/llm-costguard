# Promotions and Discount Codes

## overview

A promotion reduces an order only when its checkout terms are met and the discount is visible before purchase. This article does not create a retroactive discount. It also does not change the 30 calendar day return window.

## rules

A promotion can have an expiry, a minimum spend, product exclusions, an account limit, and a rule against combining offers. The terms displayed with that promotion govern it. The customer enters the code at checkout and confirms the discount in the order summary before placing the order. If a code fails, check spelling, expiry, eligible products, the minimum spend, and whether another offer is already on the order. One failure is not automatically a system defect.

## exceptions

Northstar does not apply a code after the order is placed unless the supplied terms or the order page explicitly allow a retroactive discount. A membership benefit does not prove that a public code will stack on top of it. A code that excludes electronics will not discount headphones, even when the cart clears the minimum. A cart under the minimum fails even when the product itself is eligible. Price match has its own 7-day clock and is not another name for a missed code.

## steps

If the order is not placed, send the customer back to checkout with the checks above. If the order is already placed, do not promise to add the code afterward. Read the supplied terms before commenting on stacking or exclusions. Treat the order summary as the proof that a code was accepted.
