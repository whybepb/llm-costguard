# Exchanges

## Which items can be exchanged

Apparel and footwear can be exchanged for a different size or colour of the same product within 30 days of delivery. Exchanges are free: there is no pickup fee and no delivery fee. The new size or colour must be available at the same price; if it costs more or less, please return the item and place a new order instead.

Each item can be exchanged only once. If the replacement size or colour does not fit either, you can still return it for a refund.

Electronics cannot be exchanged for a different model, brand or colour. If an electronics item is defective or damaged, it can be replaced with the same model within 10 days of delivery through the returns flow.

Home goods, including furniture, kitchenware, bedding and home decor, are not eligible for exchange. You can return them within 30 days of delivery and place a new order for the item you want.

## How exchanges work

Go to My Orders, select the item and tap Exchange. Choose the new size or colour and confirm your address. We pick up the original item and hand over the replacement in the same visit, so you are never without the product. Exchanges are usually completed within 3–5 business days.

Please keep the original item unused, unwashed and with all tags attached. Our delivery partner will check the tags and condition at the doorstep before handing over the replacement.

If the size or colour you want goes out of stock after you request the exchange, we will cancel the exchange and offer a full refund instead.

## Return window after an exchange

The exchanged item gets a fresh return window counted from its own delivery date: 30 days for apparel and footwear. Because each item can be exchanged only once, the exchanged item can be returned but not exchanged again.

## Exchanges outside India

Exchanges are available only for deliveries within India. International orders can be returned according to the international shipping policy, but they cannot be exchanged.

## Size help

Not sure about your size? Check the ShopNest size guide on the product page before ordering. Size and colour exchanges for apparel and footwear are free within 30 days of delivery, so you can order with confidence.
